# MEU PRIMEIRO PROGRAMA

Crie um arquivo arquivo chamado Teste.java e digite o seguinte código:

```java
public class Teste {
    public static void main(String[] args) {
        System.out.println("Ola Mundo!");
    }
}
```

## Objetivo

- Compilar e executar, garantir que o ambiente de desenvolvimento esteja funcionando corretamente.

No terminal, na pasta do arquivo, digite os seguintes comandos:

- Compilação: `javac Teste.java`
- Execução: `java Teste`

Como resultado deve aparecer a mensagem: `Ola Mundo!` no terminal.
